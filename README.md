# 🎧 Audio Sentinel AI

Real-time audio event classification system using YAMNet.

## 🚀 Features
- Audio classification using pretrained YAMNet model
- Supports MP3/WAV input
- Detects environmental sounds (speech, alarm, music, etc.)
- Clean modular Python architecture

## 🧠 Tech Stack
- Python
- TensorFlow
- TensorFlow Hub
- Librosa
